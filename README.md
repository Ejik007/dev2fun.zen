# Модуль Яндекс.Дзен RSS для Bitrix

> **Внимание!** Данный модуль является форком оригинального модуля [dev2fun.zen](https://github.com/darkfriend/dev2fun.zen). Оригинальный модуль перестал корректно работать на новых версиях 1С-Битрикс и не соответствовал актуальным критериям Яндекс.Дзена. Данная версия была доработана и адаптирована для стабильной работы в современных условиях.

Модуль предназначен для генерации RSS-ленты, полностью соответствующей требованиям Яндекс.Дзена. Он позволяет автоматически формировать фид из элементов инфоблоков с поддержкой SEO-описаний и управляющих тегов.

## Возможности

- Генерация RSS-ленты по стандартам Яндекс.Дзена.
- Поддержка SEO-описаний (ELEMENT_META_DESCRIPTION) в качестве анонса статьи.
- Настройка разрешенных HTML-тегов в контенте.
- Управление тегами `<category>` (index, comment-all, format-article) через админ-панель.
- Очистка контента от скриптов и лишнего мусора.
- Поддержка возрастного рейтинга.

## Установка

1. Перейдите в директорию модулей вашего Bitrix-проекта:
   ```bash
   cd /home/bitrix/www/bitrix/modules
   ```

2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Ejik007/dev2fun.zen.git
   ```

3. Перейдите в административную панель вашего сайта:
   `Рабочий стол -> Marketplace -> Установленные решения`.

4. Найдите модуль **"Яндекс.Дзен RSS"** (ID: `dev2fun.zen`) и нажмите **Установить**.

## Настройка

После установки перейдите в настройки модуля:
`Рабочий стол -> Настройки -> Настройки продукта -> Настройки модулей -> Яндекс.Дзен RSS`.

Здесь вы можете настроить:
- Название и описание блога.
- Инфоблоки, из которых будут браться данные.
- Список управляющих тегов.

## Использование компонента
Выгрузка доступна по ссылке из настроек модуля

Для вывода RSS-ленты создан файл (`/yandex.zen/index.php`)

```php
<?
require($_SERVER["DOCUMENT_ROOT"]."/bitrix/header.php");
$APPLICATION->SetTitle("Yandex.Zen RSS");
?>
<?$APPLICATION->IncludeComponent(
	"dev2fun:yandex.zen",
	"",
	Array(
		"COUNT" => "100",
		"FILTER_NAME" => "",
		"IBLOCK_ID" => array(), //ID инфоблоков
		"SORT_FIELD" => "created",
		"SORT_ORDER" => "desc"
	)
);?>
<?require($_SERVER["DOCUMENT_ROOT"]."/bitrix/footer.php");?>
```
